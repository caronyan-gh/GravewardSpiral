# 設定とそのほか

## 設定を変える

設定は、タイトル画面、Esc のメニュー、キャンプから開ける。項目は「基本」「ゲームプレイ」「その他」のタブに分かれていて、Q と E(パッドは L1 と R1)か、タブのクリックで切り替える。上下で項目を選び、左右または決定で変更する。取消で戻ると設定が保存される。

基本のタブ:

- 言語: 表示言語を切り替える。
- BGM・効果音の音量: それぞれの音量を調整する。
- 画面: ウィンドウと全画面を切り替える。F11 でも切り替えられる。
- ウィンドウの大きさ: 1280×720 から、画面に収まる 16:9 の大きさを選ぶ。全画面のあいだは、ウィンドウに戻したときの大きさを変える。
- 物語の書体: 文章を表示する書体を変える。
- 迷宮の線画: カラーとモノクロを切り替える。

ゲームプレイのタブ:

- 戦闘のログの速さ: 戦闘の経過を表示する速さを変える。
- 長押しの繰り返し: キーやボタンを押し続けたとき、カーソルが進む速さと迷宮で歩き続ける速さを、ゆっくり・ふつう・はやい・最速から選ぶ。
- 迷宮の地図: 「小窓と地図」「地図だけ」「使わない」を選ぶ。
- 後ろのキー: 迷宮で ↓ を押したとき、後退するか振り向くかを選ぶ。Shift を押しながらなら逆の動きになる。
- 迷宮のマウス移動: 迷宮の絵をクリックして動くかを選ぶ(動き方は「操作のしかた」の「迷宮での動き」)。
- 移動のオーバーレイ: マウスで動く領域の区切りと矢印を、迷宮の絵に薄く重ねる。マウス移動を使うときだけ変えられる。
- 呪文のレベルのタブ: 呪文を唱える画面(戦闘とキャンプ)の上のタブを、クリックで切り替えるか、マウスを載せるだけで切り替えるかを選ぶ。

その他のタブ:

- AI 設定: 自由な迷宮の文章生成に AI を使うか設定する。
- シナリオのフォルダ: シナリオの保存先を開く。

## AI を使う場合

通常のプレイに AI や API キーは必要ない。AI を使わなくても、自由な迷宮の文章は自動で用意される。

AI に文章を生成させる場合は、Claude の API キーを設定する。API の利用料金は、利用するアカウントに請求される。

## 難易度

新しく始めるときに難易度を選ぶ。選択した設定は、その世界のセーブに保存される。

- Wizardry 風(厳しい): 全滅すると亡骸が迷宮に残る。蘇生に失敗することがある。こまめな自動セーブで、失敗前へのやり直しはできない。
- 5版風(やさしい): 全滅すると町へ運ばれるが、所持金を半分失う。蘇生は必ず成功する。セーブは町に戻ったときと中断時に行う。
- カスタム: 全滅時の扱い、蘇生の成功、セーブ方法を個別に選ぶ。

全滅後の救助や蘇生については、「死亡と救助」を参照。

## クランと世界

クランは、育てたキャラクターたちの集まり。世界は、選んだシナリオで冒険を進める舞台だ。同じクランの仲間で、別の冒険を始めることもできる。

新しく始めるときに、使うクランを選べる。訓練場の「クランを書き出す」では、キャラクターの名簿をファイルに保存できる。

## シナリオを追加する

シナリオのフォルダか zip ファイルをタイトル画面にドラッグすると、シナリオを追加できる。追加したシナリオは「新しく始める」で選べる。

保存先は、設定の「シナリオのフォルダ」から開ける。自分でシナリオを作るためのシナリオエディタも、別のツールとして用意されている。

## 中断と再開

迷宮では、Esc のメニューから「中断してタイトルへ」を選ぶと、保存してタイトル画面へ戻れる。再開するときは、タイトル画面の「続きから」を選ぼう。
