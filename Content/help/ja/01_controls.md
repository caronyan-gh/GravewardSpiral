# 操作のしかた

## 基本のキー

キーボードとゲームパッドで操作できる。メニューの項目はマウスでも選べる。クリックで決定し、ホイールで一覧をスクロールする。

- 決定: Enter / Space / Z / パッドの A
- 取消・戻る: Esc / Backspace / X / パッドの B
- 移動・項目の選択: 矢印キー / WASD / 十字キー / 左スティック
- メニュー(迷宮ではキャンプ): Tab / C / パッドの Start か Y
- 地図: M / パッドの Back か X
- 一覧のページ送り: PageUp・PageDown / Q・E / パッドの LB・RB
- 全画面の切り替え: F11 / Alt+Enter

画面によって、左右キーでタブやページを切り替えることもある。各画面の下に表示される操作案内も確認しよう。

## 迷宮での動き

- ↑: 前へ1歩進む。
- ←・→: その場で左右に向きを変える。
- ↓: 設定の「後ろのキー」に従って、1歩後退するか、後ろを向く。
- Q・E(パッドは LB・RB): 向きを変えずに、左右へ1歩移動する。
- 決定: 目の前や足元を調べる。扉や宝箱を調べたり、階段を使ったりできる。
- Shift(パッドは L2)を押しながら ↓: 「後ろのキー」の設定と逆の動きをする。通常が後退なら振り向き、通常が振り向きなら後退する。

マウスでも動ける(設定の「迷宮のマウス移動」)。迷宮の絵の上では、カーソルがその場所の動きの矢印に変わり、クリックするとその動きをする。歩く動きは、押したままにすると歩き続ける。

- 右上の小さな円: 調べる(決定と同じ)。
- 上: 前へ進む。
- 左上・右上: 左右に向きを変える。
- 左下・右下: 左右へ横歩き。
- 下の左半分: 振り向く。下の右半分: 1歩下がる。

設定の「移動のオーバーレイ」をオンにすると、この区切りと矢印が絵の上に薄く出る。

## Esc のメニュー

Esc でメニューを開き、ヘルプ・設定・終了を選べる。迷宮では「キャンプ」や「中断してタイトルへ」も選べる。

## ヘルプの読み方

上下キーで左側の目次を選ぶと、右側にその項目の本文が表示される。本文の続きは、左右キー・PageUp・PageDown・ホイールでスクロールできる。取消かメニューのキーでヘルプを閉じる。

## キーの割り当て

キーの割り当ては、ユーザーデータフォルダ(%LOCALAPPDATA%\GravewardSpiral)の input.json を編集して変更できる。全画面切り替えのキーは変更できない。
