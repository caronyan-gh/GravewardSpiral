# 操作のしかた

## 基本のキー

キーボードとゲームパッドで遊べる。メニューはマウスでも選べる(クリックと、ホイールでの送り)。

- 決定: Enter / Space / Z / パッドの A
- 取消: Esc / Backspace / X / パッドの B
- 移動・項目の選択: 矢印キー / WASD / 十字キー / 左スティック
- メニュー(迷宮ではキャンプ): Tab / C / パッドの Start か Y
- 地図: M / パッドの Back か X
- 一覧のページ送り: PageUp・PageDown / Q・E / パッドの LB・RB
- 全画面の切り替え: F11 か Alt+Enter

## 迷宮での動き

- ↑ で前進、← → でその場で回転する。
- ↓ は、設定の「後ろのキー」で決めた動き(1歩下がる か 振り向く)になる。
- Q・E(パッドは LB・RB)で、向きを変えずに横へ1歩動く。
- 決定で、目の前や足元を調べる(階段・扉・宝箱など)。
- Shift(パッドは L2)を押しながら後ろのキーを押すと、設定と逆の動きになる。たとえば「1歩下がる」にしていれば、振り向く。

## Esc のメニュー

Esc を押すと小さなメニューが開く。ここから、ヘルプ・設定・やめる(迷宮では「中断してタイトルへ」)に進める。迷宮では「キャンプ」もここから開ける。

## キーの割り当て

割り当ては、ユーザーのデータフォルダ(%LOCALAPPDATA%\GravewardSpiral)にある input.json に書かれている。変えたいときは、このファイルを書き換える。全画面の切り替えだけは変えられない。
