# クラスの分離の記録

docs/class-data-design.md の「移し方と確かめ方」で使う、分離の前の動きの記録。

- `class_behavior.txt`: `ClassBehaviorRecordTests` が比べる。書き直すのは、変わった理由を書いてから `GW_UPDATE_RECORDS=1` で。
- `bots_*.txt`: 三部作のボットの通し。乱数は固定なので、動きが同じなら同じ数字になる。各段のあとで、同じコマンドで流して比べる。

```
dotnet build tools/GravewardSpiral.Sim -c Release -o out/simcheck
out/simcheck/GravewardSpiral.Sim.exe --campaign --runs 4 --scenario gravekeeper > bots_gravekeeper.txt
out/simcheck/GravewardSpiral.Sim.exe --campaign --runs 4 --scenario sunken --level 5 > bots_sunken.txt
out/simcheck/GravewardSpiral.Sim.exe --campaign --runs 4 --scenario Content/scenarios/devourer --level 8 > bots_devourer.txt
```
